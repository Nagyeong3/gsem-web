# GSEM v0.20.0 변경사항

## 납품 차수 통합현황

- 상단(차수) 필터: 사업 선택, 납품 부대, 납품완료 상태 복수선택, 계약상 납기 시작·종료일.
- 하단(아이템) 필터: 품명·품번 부분일치(대소문자 무시), 조달원 복수선택.
- 아이템 필터는 **펼친 하위 품목에만** 적용하며 상위 차수의 집계, 납품완료 상태를 변경하지 않음.
- 완료된 차수를 숨기는 체크박스 제공. 숨김 설정은 브라우저에 저장됨.
- 전체/회전익/고정익 시연 선택 UI 제거.
- 하위 아이템 테이블에서 PR/PO 번호를 노출함. 번호가 없는 품목은 `-` 표시.
- 상·하위 테이블은 사용 가능 너비에 맞춰 표시하고 너비가 부족하면 **테이블 내부** 가로 스크롤 제공.
- 사이드바 하단에 `GSEM v0.20.0` 버전 표시.

## 납품완료·일정 계산

- 납품완료는 **차수 전체 품목**을 기준으로 판단하며, 해당 차수에 품목이 하나 이상 있고 모든 `date_deliver`가 등록돼야 완료.
- 계약상 납기 종료일 비교는 날짜만 비교하여 해당 일자의 시각까지 포함.
- SQL Server ODBC에서 `? IS NULL`의 매개변수 타입이 모호해지는 기존 방식 제거; 선택된 날짜 조건만 SQL에 추가.
- 미완료 중 계약상 납기일까지 7일 이하이거나 기한이 지난 차수는 빨간색, 그 외는 노란색으로 표시.

## 운영 적용 참고

- SQL Server 컬럼: `Match_Sub_Contract_Item.purchase_request_Number`, `purchase_order_Number`.
- CORS 전체 Origin 허용 `allowed_origins=("*",)`은 앞선 요청을 반영한 **문제 확인용 설정**. 운영 전 허용 Origin 제한 권장.
- `GSEM_DATA_SOURCE=sqlserver`의 실제 SQL Server, 실제 납품 데이터는 해당 환경에서 검증 필요.

## 검증 상태

- Python/FastAPI 테스트 21개 통과.
- 변경 TS/TSX 구문 검증 통과.
- 의존성 미설치·오프라인 환경 때문에 TypeScript 전체 typecheck, 프론트 build, Playwright 브라우저 검증은 실행하지 못함.
