# 프로토타입 V8 — 장비 이미지 조회 UX

## 목적

장비 검색과 통합 상세에서 대표 이미지를 빠르게 확인할 수 있도록 조회 경험을 확장한다. 실제 이미지 저장소와 업로드 정책은 확정하지 않고, 공개 저장소용 일반화 목업 이미지로 화면과 API 계약만 검증한다.

## 구현 범위

- 검색 결과 품명 셀의 44×44 대표 썸네일
- 마우스 호버와 키보드 포커스 시 320×210 미리보기
- 썸네일·패널·상세 이미지 선택 시 확대 대화상자
- 검색 우측 상세 패널의 대표 이미지
- 장비 통합 상세 상단의 176×112 대표 이미지
- 이미지가 없거나 불러오지 못했을 때 대체 상태
- Mock Adapter와 FastAPI HTTP 응답의 동일한 `images[]` 계약
- 라이트·다크 모드와 1440×900 화면 검수

검색 표에는 이미지 전용 열을 추가하지 않았다. 품명과 대표 이미지를 한 셀에 배치하여 기존 정보 밀도와 가로 폭을 유지했다.

## 프로토타입 가정

- 한 품목은 여러 이미지를 가질 수 있으며 `isPrimary`가 대표 이미지를 표시한다.
- 목업에서는 썸네일과 원본 URL이 같은 정적 SVG를 가리킨다.
- FastAPI 인메모리 Repository가 기존 JSON 품목에 일반화 이미지를 보강한다.
- 실제 장비 사진, 회사 품번, 업체·사업·직원 정보는 사용하지 않는다.

## 미확정

- 이미지 파일을 DB, 파일 서버 또는 문서 시스템 중 어디에 저장할지
- ERD의 이미지 메타데이터 테이블과 품목 FK
- 대표 이미지 선정, 정렬 순서, 다중 이미지 최대 개수
- 업로드·교체·삭제 권한과 감사 이력
- 허용 확장자, 파일 크기, 해상도, 악성 파일 검사
- 이미지 버전 및 캐시 정책
