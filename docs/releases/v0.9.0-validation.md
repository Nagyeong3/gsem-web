# GSEM v0.9.0 검증 결과

검증일: 2026-10-22 (한국 시간). 기준 브랜치: `feature/main-workflow-page`, 기준 커밋: `0376c62a4a487b0634c95b286053d97d0aed9b62`. 안정화 작업 브랜치: `agent/v0.9.0-stabilization`. 최종 커밋은 반입 ZIP의 `manifest.json`에 기록한다.

## 변경 결과

- 대시보드 지표·납품 차트·최근 변경/납품 목록을 표시 컴포넌트로 분리했다. 페이지는 조회·라우팅·상태 표시를 담당한다. 동작하지 않던 최근 이력·납품 전체 보기 링크를 연결했다.
- 공통 SearchField로 대시보드·장비 검색·통합현황·납품·변경 신청·변경 이력의 Enter/버튼 검색을 통일했다. 입력 중 조회하지 않으며 한글 조합 중 Enter·229 키 이벤트를 보호한다.
- 공통 필터 Select와 접근 가능한 삭제 버튼을 분리했다. 삭제는 해당 조건만 제거하며 조건 변경 시 첫 페이지로 돌아간다. 장비 검색·통합현황은 URL을 조건의 정본으로 사용한다. 연속 상태 갱신에서도 다른 조건·데이터 공급자 값을 보존한다.
- 사이드바 경로 판정을 공통 함수로 분리하고 `/equipment-master`와 `/equipment`를 구분한다. 상세 경로는 부모 메뉴만 선택한다. 기준 브랜치에 이미 있던 정확 일치 처리를 유지·회귀 검증했다.
- 장비 검색과 통합현황의 엑셀형·최적화형 컬럼 너비를 각각 localStorage에 저장·복원한다. 식별자 기반 저장으로 필터·빈 결과·보기 전환에도 보존한다. 손상값·저장 차단은 화면 오류 없이 처리하며 너비 초기화는 필터 초기화와 분리한다. 드래그 이벤트는 종료·취소·컴포넌트 해제 시 정리한다.
- 기준 브랜치에서 누락됐던 Mock 역할 선택 UI를 복원했다. 통합현황 목업의 기존 금지 직급 표기는 책임·선임으로 바꾸었으며 데이터 건수·수량·편집/조회 구조는 유지했다.
- 누락된 통합현황 OpenAPI 경로를 문서·백엔드 검사에 포함하고 기존 Ruff 오류를 정리했다. 503 설정/연결 실패를 잘못된 NOT_FOUND 대신 SERVICE_UNAVAILABLE로 구분했다.
- 배포용 Mock/API 빌드, SPA 경로·API 프록시를 지원하는 로컬 검수 서버, ZIP 패키징·해시 확인 도구, 오프라인 의존성과 적용·복원 가이드를 추가했다.

## 브라우저 확인

Chromium 154를 Playwright 실행 파일로 지정했다. 대시보드와 통합현황의 1440×900 캡처를 직접 검토했다. 한글 표시·사이드바 선택·검색·필터 삭제·컬럼 너비 복원·가로 넘침을 확인했다. 기존 기준 시안·캡처 파일은 변경하지 않았고 검사 산출물은 `test-results/screenshots` 및 패키지 `evidence`에 저장한다. 자동 검사가 모든 화면의 픽셀 일치를 보장한다는 의미는 아니다.

## SQL Server와 대상 OS의 별도 검증

**SQL Server 실데이터는 검증하지 않았다.** 이 환경에 DB 연결 정보·ODBC·승인된 DB가 없다. Pytest는 fake DB 연결을 통해 조건 바인딩·페이징·읽기 전용 모드·예외 시 연결 해제를 검사한다. API E2E의 통합현황은 DB 응답 fixture를 사용하며 실제 SQL Server 조회 성공이 아니다. 나머지 API E2E는 FastAPI와 JSON 인메모리 Repository 사이 실제 HTTP 통신을 검사한다.

최종 스키마, 실제 데이터 건수·중복·NULL·수량 합계·계약별 날짜·사업별 동일 품번·CSV·이미지·검색 성능은 폐쇄망에서 별도 확인해야 한다. 체크리스트와 기존 SELECT 점검문 위치는 적용·복원 가이드에 있다. DB 스키마·데이터 변경은 없다.

Windows x64 CPython 3.12용 wheel과 npm 선택 패키지는 준비했으나 Windows에서 실행하지 않았다. Windows 런타임·ODBC·브라우저는 사전 준비 대상이며 설치 프로그램은 ZIP에 포함하지 않는다.

## Git 전달

GitHub read-only HTTPS Git 조회는 성공했다. GitHub API의 저장소 조회는 `Forbidden`으로 차단되어 이 환경에서 Draft PR 생성은 완료하지 못했다. 인증 값을 새로 요청하거나 노출하지 않았다. 소스·패치·Git 복원 bundle과 가이드는 이 제한과 독립적으로 전달한다. main 병합·운영 배포·환경 Publish는 수행하지 않았다.
