## V7 이후 우선순위

### 1. 실제 DB 연결 준비

다음 자료를 받은 뒤 시작한다.

- 최종 ERD와 테이블 정의서
- 익명화한 테이블별 1~3개 행
- 공통코드 목록
- Access 버전, 실행 OS와 비트 수
- 읽기·쓰기 범위와 동시 사용자 수

첫 구현은 읽기 전용 `MsAccessGsemRepository`다. Router와 프론트 계약은 변경하지 않는다.

### 2. 업무지식 확인 후 화면 고도화

- 실제 품목·납품·변경 상태와 처리 순서
- 역할별 권한
- 단종 발견부터 대체품 확정까지의 흐름
- 단종 문의 점검 주기와 회신 처리
- 검색 우선순위와 SERD·연관 품번 포함 여부

### 3. 단종 점검 기능

업무 흐름 확인 전에는 자동발송을 구현하지 않는다. 1차 후보 범위는 다음과 같다.

- 내 담당 품목 점검 목록
- 최근 확인일과 다음 점검일
- 문의·회신 상태
- 업체 정보
- 메일 문안 생성 또는 `.eml` 다운로드
- 회신 결과와 대체 검토 연결

사내 메일 직접 연동은 보안·인프라 승인 후 별도 단계로 진행한다.
