# 미확정 질문 목록

## 1. 반드시 회사에서 확인해야 하는 질문

아래 질문은 화면과 데이터 구조를 동시에 좌우한다. 가능하면 실제 사례 한 건을 따라가며 답을 기록한다.

1. 지원장비 정보가 처음 생긴 시점부터 납품 완료까지 누가 어떤 순서로 어떤 시스템과 자료를 사용하는가?
2. 단종 사실을 처음 인지한 시점부터 대체품을 결정하고 기존 사업에 반영하기까지 누가 어떤 순서로 처리하는가?
3. 현업에서 실제 사용하는 장비 상태, 납품 상태, 변경 신청 상태의 명칭과 순서는 무엇인가?
4. 하나의 실제 장비가 체계개발·양산·수출 단계에서 여러 품번을 가질 때 동일 장비임을 판단하는 기준은 무엇인가?
5. 단종품 하나에 여러 대체품이 있을 수 있는데, 반대로 대체품 하나가 여러 단종품을 대체할 수도 있는가?
6. 대체 관계가 사업마다 달라질 수 있는가? 달라진다면 어떤 사업에서 어떤 대체품을 쓰는지 별도로 관리해야 하는가?
7. 지원장비, 기본불출품목, 조종장구류 점검장비, 표준기는 어떤 공통 항목을 가지고 어떤 항목이 서로 다른가?
8. 사업별 납품 수량과 일정은 어디에서 만들어지며, 변경·부분 납품·지연은 어떻게 기록하는가?
9. 일반 조회자, 지원장비 담당자, 구매 담당자, 승인자는 각각 어떤 정보를 조회·등록·수정·승인할 수 있는가?
10. 장비 정보나 담당자를 잘못 변경했을 때 원복하는가, 정정 이력을 추가하는가? 과거 기록은 누가 볼 수 있는가?

## 2. 프로토타입 제작 전 확인하면 좋은 질문

- 장비 검색 결과에서 상세 화면을 열지 않아도 반드시 보여야 하는 열은 무엇인가?
- 가장 자주 사용하는 검색어와 필터 세 가지는 무엇인가?
- 장비 상세 화면에서 가장 먼저 확인하는 정보는 무엇인가?
- 대시보드의 `확인이 필요한 업무`는 개인 담당 업무인가, 전사 현황인가?
- 납품 지연은 예정일 초과로 자동 계산하는가, 담당자가 직접 지정하는가?
- 변경 이력 트리에는 단종·대체 관계만 표시하고 담당자·사양 변경은 시간순 로그로 구분하면 되는가?
- 사용자는 대체품 계보에서 무엇을 클릭하고 어떤 상세정보를 확인해야 하는가?
- 하나의 장비에 여러 담당자가 동시에 배정될 수 있는가?

## 3. DB 설계 단계에서 확인할 질문

- 품번과 장비의 관계는 일대일인가, 한 장비에 여러 품번이 존재하는가?
- 품번 변경과 대체품 변경은 업무상 어떻게 구분하는가?
- 장비·사업·기종·계통 관계에 적용 시작일과 종료일이 필요한가?
- 사업과 기종은 독립적으로 장비에 연결되는가, 특정 사업이 특정 기종에 종속되는가?
- 납지와 납품 일정은 사업, 계약, 장비 중 무엇을 기준으로 생성되는가?
- 계획 수량, 발주 수량, 입고 수량, 납품 수량을 모두 보존해야 하는가?
- 담당자 변경의 효력일과 종료일을 관리해야 하는가?
- 획득 가능·단종 상태의 변경 이력을 영구 보존해야 하는가?
- 변경 신청과 실제 반영 이력을 별도 데이터로 관리해야 하는가?
- 품목 유형별 개별 속성은 얼마나 다르며 신규 유형이 추가될 가능성이 있는가?

## 4. 후순위 질문

- SERD 자동번역 결과를 누가 검토하고 표준 영문명을 어떻게 확정하는가?
- 출력할 엑셀·PDF의 공식 양식이 존재하는가?
- 개인별 컬럼·필터 설정을 어디까지 저장하는가?
- 엑셀 Import 시 신규 등록과 기존 데이터 수정을 어떻게 구분하는가?
- 교정 만료 알림과 교정 이력까지 관리해야 하는가?
- 문서 원본을 시스템에 저장할지 기존 시스템 링크만 관리할지?
- 단종 확인 메일의 표준 양식, 수신자, 회신 처리 방식은 무엇인가?
- `3S`의 정확한 업무상 의미는 무엇인가?

## 5. 답변 기록 원칙

- 실제 품번과 직원 이름 대신 익명 표기를 사용한다.
- `현재 실제 업무`, `희망 기능`, `프로토타입 가정`을 구분한다.
- 답변자가 다르면 역할을 기록하되 실명은 저장소에 남기지 않는다.
- 결론이 나지 않은 내용은 다수 의견으로 합치지 않고 미확정으로 남긴다.
