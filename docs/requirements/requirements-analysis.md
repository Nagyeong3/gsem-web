# 지원장비 관리시스템 요구사항 분석표

## 1. 문서 목적

요구사항 001~026을 화면, 데이터 및 후속 확인사항 관점에서 비교하기 위한 분석표다. 이 문서의 `DB 영향도`는 설계 우선순위를 판단하기 위한 상대적 표시이며 테이블 구조를 확정하지 않는다.

## 3. 연관 요구사항 묶음

### 통합 검색과 상세

- 001, 003, 008, 011, 014, 015, 016, 017, 018, 019
- 검색 결과와 장비 상세가 같은 기준 데이터를 바라봐야 한다.

### 납품 현황

- 002, 009, 011, 013
- 구매 이력과 납품 진행 상태를 같은 개념으로 합치지 말고 관계를 확인해야 한다.

### 변경과 대체 추적

- 003, 007, 010, 021, 025, 026
- 일반 속성 변경, 담당자 변경, 단종·대체 관계, 수리·하자 사건을 하나의 화면에서 보여주더라도 원래 사건 유형은 구분해야 한다.

### 개인화와 데이터 반출입

- 006, 012, 013, 020
- 개인 화면 설정, 단순 다운로드, 대량 Import는 목적과 권한이 다르므로 별도 기능으로 취급한다.

### 문서·자료

- 022, 023, 024, 025
- 현재 우선순위에서는 상세 저장 구조와 화면 설계를 보류한다.

## 4. 1차 프로토타입 판단

1차 프로토타입에서는 검색, 상세, 납품 일정, 변경·대체 이력의 연결성을 검증한다. 실제 승인, 데이터 연계, 파일 저장, 메일, Import·Export는 동작시키지 않는다.

요구사항 027 이후는 내용이 구체화될 때까지 분석 대상에서 제외한다.
