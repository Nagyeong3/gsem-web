# UI Mockups

지원장비 관리시스템 프론트엔드 구현을 위한 최종 정적 시안입니다.

- `dashboard.png`: 메인 대시보드
- `equipment-search.png`: 장비 검색
- `change-history.png`: 장비 변경 이력

현재 파일은 화면 구조와 디자인 검토를 위한 목업이며 실제 업무 데이터는 포함하지 않습니다.

## 추가 시안

`extended/`에는 기존 시안의 디자인 기준을 확장한 1440×900 정적 시안이 있습니다.

- `extended/equipment-detail.png`: 장비 통합 상세
- `extended/delivery-schedule.png`: 납품 일정 관리
- `extended/change-request.png`: 변경 신청 및 처리 현황

추가 시안의 공통 규격은 `docs/design/design-system.md`, 검수 결과는 `docs/design/mockup-qa.md`를 참고합니다.
