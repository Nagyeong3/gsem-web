# 지원장비 관리시스템 업무 용어집 초안

업무 용어를 개발 과정에서 일관되게 사용하기 위한 초안이다. 현업 정의가 확인되지 않은 용어는 추측하지 않는다.

| 용어 | 현재 이해 | 상태 |
|---|---|---|
| 지원장비 | 항공기 운용·정비 등을 지원하기 위해 관리하는 장비. 정확한 포함 범위는 추가 확인이 필요하다. | 정의 확인 필요 |
| 기본불출품목 | 지원장비 외 별도 관리 대상 중 하나. 품목 유형으로 필터링할 수 있어야 한다. | 세부 정의 확인 필요 |
| 조종장구류 점검장비 | 조종장구류 점검과 관련된 별도 관리 품목 유형. | 세부 정의 확인 필요 |
| 표준기 | 지원장비 외 별도 DB 관리 대상 품목 유형. | 정의 확인 필요 |
| 품번 | 품목을 식별하기 위해 사용하는 번호. 하나의 실제 장비에 여러 품번이 생길 수 있는지 확인이 필요하다. | 부분 확인 |
| SERD | 지원장비 관련 기본 정보 단위 또는 문서. 번호, 크기, 중량, 주용도 등의 정보가 언급됐다. | 정확한 정의 확인 필요 |
| 기종 | 장비가 적용되는 항공기 또는 무기체계 구분. 한 장비에 여러 기종이 적용될 수 있다. | 관계 확정 |
| 사업 | 장비가 포함되는 프로젝트 또는 사업 구분. 한 품목에 여러 사업이 포함될 수 있다. | 관계 확정 |
| 계통 | 장비의 적용 영역을 구분하는 분류. 한 장비에 여러 계통이 적용될 수 있다. | 관계 확정 |
| 납지 | 장비가 납품되는 장소 또는 대상 구분. 정확한 단위는 확인이 필요하다. | 정의 확인 필요 |
| 품보 형태 | 지원장비별로 관리하는 품질보증 형태. 종류와 코드 체계는 아직 확인되지 않았다. | 요구사항만 확정 |
| 교정 | 장비의 교정 대상 여부, 주기, 사내외 수행 여부 및 교정소 정보를 관리하는 업무. | 부분 확인 |
| 단종품 | 더 이상 획득하기 어려운 것으로 관리되는 품목. 판정 기준과 확정 주체는 미정이다. | 부분 확인 |
| 대체품 | 단종품을 대신해 적용하는 품목. 하나의 단종품에 여러 대체품이 존재할 수 있다. | 일부 관계 확정 |
| 체계개발 | 장비·품번 관계에서 언급된 사업 단계 또는 구분. 양산과 품번 체계가 다를 수 있다. | 정의 확인 필요 |
| 양산 | 체계개발 이후 생산·납품과 관련된 사업 단계 또는 구분. | 정의 확인 필요 |
| 수출 | 수출 사업 또는 수출용 정보 관리 구분. 영문 SERD 요구와 연관된다. | 정의 확인 필요 |
| 구매품 | 외부 구매를 통해 획득하는 품목. 단종 조사와 Datasheet 관리 요구가 있다. | 부분 확인 |
| 개발품 | 개발 과정을 통해 확보한 품목. 개발 단계 산출물 관리 요구가 있다. | 부분 확인 |
| 3S | 개발품 관련 자료로 언급된 용어. | 정의 확인 필요 |

## 사용 원칙

- 현업에서 사용하는 명칭을 우선한다.
- 동일한 의미의 유사 용어가 발견되면 임의로 합치지 않고 차이를 확인한다.
- 화면 표시명, API 용어, DB 용어가 달라질 경우 매핑을 기록한다.
- 실제 사례는 익명화해 기록한다.
