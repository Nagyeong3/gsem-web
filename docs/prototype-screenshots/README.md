# 프로토타입 실행 화면

Playwright로 실제 프로젝트를 실행하여 1440×900 환경에서 검수한 전체 프로토타입 화면이다.

- `dashboard.png`
- `equipment-search.png`
- `equipment-detail.png`
- `delivery-schedule.png`
- `change-request.png`
- `change-history.png`

각 화면의 `*-dark.png` 파일은 동일 화면의 다크 모드 검수본이다. 모든 데이터는 공개 저장소용 일반화 목업이다.

## 동작 상태

`flows/`에는 다음 사용자 동작과 예외 상태를 순서대로 기록한다.

1. 대시보드 통합 검색 입력과 검색 결과 이동
2. 장비 검색의 사업 필터, 정렬, 페이지 이동
3. 빈 검색 결과와 잘못된 품목 식별자
4. 납품 완료 상태 필터
5. Mock 역할 선택과 일반 조회자 권한
6. 변경 신청 초안 작성과 브라우저 메모리 보관
7. 대체 이력 검색과 분기 장비 선택
8. 미제공 기능 안내와 다크 모드
9. HTTP API 로딩, 오류, 재시도 복구

모든 파일은 1440×900 PNG이며 자동검사에서 캔버스 크기, 가로 넘침, 콘솔 오류와 핵심 텍스트를 함께 확인한다.
