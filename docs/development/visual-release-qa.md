# 프로토타입 V2 시각 검수 결과

## 검수 기준

- 첨부 레퍼런스의 벤토 그리드, 명확한 정보 우선순위, 얇은 경계, 절제된 색상
- 기존 디자인 시스템의 1440×900 캔버스, 176px 사이드바, 58px 헤더
- Noto Sans KR 기반 한글 자간·행간과 표 정렬
- 라이트·다크 모드의 동일한 컴포넌트 구조
- 과도한 그라디언트·그림자·글래스모피즘 없이 업무 집중도 유지

## 세부 판정

- 대시보드는 핵심 업무 12건을 가장 강하게 강조하고 나머지 KPI, 차트, 목록 순으로 시선이 이동한다.
- 장비 검색은 필터·표·상세 패널의 경계와 밀도가 일관되며 표 열과 상태 배지가 겹치지 않는다.
- 장비 통합 상세는 상단 요약과 좌우 정보 카드로 많은 데이터를 과밀하지 않게 분리한다.
- 납품 일정은 KPI, 필터, 10행 표, 선택 상세가 한 화면에서 비교 가능하다.
- 변경 신청은 목록과 전후 비교·처리 과정의 주종 관계가 명확하다.
- 페이지 제목 26px, 설명 13px, 본문 12~13px, 표 행 48px 규격이 화면마다 유지된다.
- 책임·선임 외 직급, 기준정보 관리 메뉴, 실제 회사 데이터, 깨진 한글과 한자는 없다.
- 카드와 버튼의 Hover, 선택 메뉴, 테마 전환은 150~180ms 범위의 절제된 효과를 사용한다.
- 강한 그라디언트 메시는 적용하지 않고 핵심 파란색 카드와 상태색만 강조해 전사 업무 화면의 가독성을 우선한다.

## 검수 중 발견하고 수정한 내용

1. 필터 조작 후 화면 캡처 시점을 기본 화면과 분리해 실제 기본 레이아웃을 검수할 수 있도록 수정했다.
2. 납품 일정 데이터가 비동기로 로딩되기 전에 캡처되어 0건으로 보이던 문제를 발견했다.
3. 납품 일정 10건 로딩을 확인한 후 캡처하도록 자동검사를 수정했다.
4. 추가 화면의 다크 모드 캡처와 스크롤 위치 0, 가로 넘침, 콘솔 오류 검사를 추가했다.

## 최종 판정

프로토타입 V2는 2차 공개용 디자인 품질 기준을 충족한다. `release/prototype-v2` 생성이 가능하다.
