# 납품 일정 관리 화면 검수 기록

## 구현 범위

- 대시보드의 납품 예정·지연 지표에서 납품 일정 화면으로 이동
- 사업, 기종, 납지, 진행 상태 필터와 품번·품명·사업·납지 통합 검색
- 계획·발주·입고·납품 수량 및 납품 예정일 비교
- 선택 일정의 사업, 기종, 납지, 담당자, 수량 상세 표시

## 자동 검사

| 검사 | 결과 |
|---|---|
| TypeScript 타입 검사 | 통과 |
| ESLint | 통과 |
| Vitest | 9개 파일, 20개 테스트 통과 |
| 프로덕션 빌드 | 통과 |
| Playwright 납품 일정 시나리오 | GitHub Actions에서 확인 |

## 프로토타입 가정

- 확인된 납품 상태값은 `예정`, `진행`, `완료`다.
- `delivery_month`, `receipt_month`는 현재 `YYYY-MM-DD` 날짜로 해석한다.
- 발주·입고·납품 수량과 단계의 실제 산정 규칙은 미확정이다.
- 지연 판정 기준은 미확정이므로 프론트에서 날짜를 비교해 자동 판정하지 않는다.
- 실제 계약·납품 데이터가 아닌 일반화된 목업값만 사용한다.
