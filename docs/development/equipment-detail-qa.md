# 장비 통합 상세 화면 검수 기록

## 구현 범위

- 장비 검색 결과의 `전체 상세` 버튼과 `/equipment/:itemId` 경로 연결
- 품목 기본정보, 복수 사업·기종·계통, 담당자, 사업별 납지 표시
- SERD, 품보 형태, 교정정보, 단종·대체 관계 요약 표시
- 데이터가 없거나 업무 규칙이 미확정인 항목을 임의 값으로 보정하지 않음

## 자동 검사

| 검사 | 결과 |
|---|---|
| TypeScript 타입 검사 | 통과 |
| ESLint | 통과 |
| Vitest | 8개 파일, 18개 테스트 통과 |
| 프로덕션 빌드 | 통과 |
| Playwright 통합 상세 시나리오 | GitHub Actions에서 확인 |

로컬 작업 환경에는 Playwright Chromium 실행 파일이 없어 브라우저 검사를 실행하지 못했다. 테스트 코드는 장비 검색에서 상세 화면으로 이동하고, 복수 사업·담당자 표시, 금지 문구, 가로 넘침을 확인하도록 작성했다. 브라우저 실행 결과는 PR의 GitHub Actions를 최종 기준으로 삼는다.

## 화면·데이터 검수 기준

- 공통 사이드바, 상단 헤더, 색상, 여백, 카드 규격 재사용
- 로그인 사용자는 `김책임`으로 유지
- 담당자 직급은 책임·선임만 사용
- `기준정보 관리` 메뉴 및 사원·대리·과장 직급 미사용
- 품목 하나에 여러 사업과 여러 담당자가 연결될 수 있도록 표시
- 실제 회사 품번·사업명·담당자·납지 대신 일반화된 목업값 사용
- 실제 변경 처리 기능은 비활성화하고 조회 흐름만 제공

## 프로토타입 가정

- 관리 품목 유형의 실제 DB 저장 위치와 공통코드는 아직 미확정이다.
- 정·부 담당자 구분은 프론트 확장 모델이며 현재 ERD에는 반영되지 않았다.
- SERD, 품보 형태, 교정정보, 대체 관계는 API에 값이 있는 경우에만 표시한다.
