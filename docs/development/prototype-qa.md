## 상호작용 검수

- 대시보드에서 장비 검색 화면으로 이동
- 검색어 입력과 복합 필터
- 선택 조건 제거와 전체 초기화
- 검색 결과 없음 상태
- 정렬과 페이지 이동
- 품목당 한 행 유지
- 검색 행 선택과 상세 패널 표시
- 1440×900 문서 전체의 가로 Overflow 미발생

## 시각 검수

- 사이드바 176px와 상단 헤더 58px를 두 화면에 동일 적용
- 로그인 사용자 `김책임` 유지
- `기준정보 관리` 메뉴 미사용
- 책임·선임 외 직급 미사용
- MUI Icons 사용
- 과도한 그림자·글래스모피즘·장식용 그래프 미사용
- 상태별 색상과 텍스트 레이블 동시 사용
- 검색표의 상태와 최근 변경일까지 첫 화면에 표시
- 실제 정보 대신 일반화한 목업값 사용

## 발견하고 수정한 문제

1. 최신 ESLint와 React Hooks 플러그인의 Peer Dependency 범위가 맞지 않아 ESLint 9 호환 버전으로 고정했다.
2. MUI 검색창의 접근성 이름이 바깥 컨테이너에 연결되어 자동 입력이 실패했다. 실제 `input` Slot으로 접근성 속성을 이동했다.
3. 실행 환경에 한글 시스템 글꼴이 없어 한글이 네모 문자로 표시됐다. `Noto Sans KR Variable` 웹폰트를 애플리케이션에 포함했다.
4. 사이드바 시스템명이 두 줄로 접혔다. 글꼴 크기와 줄바꿈 규칙을 조정해 한 줄로 통일했다.
5. 장비 상세 패널을 연 상태에서 표의 상태·최근 변경일 열이 가로 스크롤 뒤에 숨었다. 상세 패널과 표 밀도를 조정해 1440px에서 전체 주요 열이 보이도록 수정했다.

## 남아 있는 제약

- 대시보드와 장비 데이터는 실제 집계가 아닌 목업이다.
- 실제 API와 DB 연동 시 서버 페이징 및 정렬 정책을 다시 확인해야 한다.
- 변경 이력과 변경 신청 메뉴는 후속 범위이며 현재 안내만 제공한다.
- 실제 다운로드와 통합 상세 이동 버튼은 의도적으로 비활성화했다.
