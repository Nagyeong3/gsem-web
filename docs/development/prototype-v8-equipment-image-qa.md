## 직접 확인한 내용

- 검색 표는 기존 열 수를 유지하며 품명 셀 안에서 이미지와 텍스트가 겹치지 않는다.
- 44px 썸네일 적용 후 5개 행, 페이지 이동과 하단 여백이 900px 화면 안에 표시된다.
- 호버 미리보기는 선택 행 옆에 나타나며 우측 상세 패널과 캔버스 밖으로 잘리지 않는다.
- 확대 대화상자의 제목, 닫기 버튼, 이미지가 명확하고 배경 대비가 충분하다.
- 통합 상세 상단에서 이미지, 품목 요약, 관련 화면 버튼이 한 행에 정렬된다.
- 전체 페이지 캡처에서 하단 안내 영역까지 잘림이나 겹침이 없다.
- 라이트·다크 모드 모두 목업 SVG 배경과 테두리 대비가 유지된다.
- 콘솔 오류, 한글 깨짐, 금지 직급, 기준정보 관리 메뉴, 실제 회사 데이터가 없다.

## 발견·수정 사항

1. MUI 대화상자 닫힘 전환이 끝나기 전에 테스트가 DOM을 확인하여 단위 테스트가 실패했다.
   - 전환 완료를 기다리는 비동기 검증으로 수정했다.
2. 다크 모드 캡처에서 테마 전환 버튼의 툴팁이 남았다.
   - 캡처 전 포인터를 콘텐츠 영역으로 이동하고 전환 종료를 기다리도록 수정했다.
3. 검색 표에 이미지 전용 열을 추가하면 기존 1440px 정보 밀도를 해칠 수 있었다.
   - 품명 셀 안에 대표 썸네일을 결합하는 구조로 확정했다.

## 남은 제약

목업 SVG는 화면·계약 검증용이며 실제 장비 사진의 비율, 용량, 접근 권한과 로딩 성능을 대표하지 않는다. 실제 저장 방식이 결정되면 CDN·파일 서버 URL, 썸네일 생성, 권한 오류와 캐시 정책을 다시 검증해야 한다.
