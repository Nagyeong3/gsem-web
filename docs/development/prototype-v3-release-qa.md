# 3차 프로토타입 릴리즈 검수 결과

## 검수 개요

- 검수 대상: `develop/prototype` 반영 후보 화면 6종
- 화면 모드: 라이트·다크 모드 각각 검수
- 캡처 규격: 1440×900 PNG, 총 12장
- 검수 기준: 공통 프레임, 내비게이션, 타이포그래피, 색상, 정렬, 반응형 레이아웃, 주요 화면 이동, 금지 항목
- 검수 결론: **통과**

## 기능 및 이동 경로

- 사이드바 순서를 `대시보드 → 장비 검색 → 납품 일정 → 변경 이력 → 변경 신청`으로 통일했다.
- 모든 화면에서 `납품 일정` 메뉴를 직접 선택해 `/deliveries`로 이동할 수 있다.
- 대시보드의 납품 관련 지표를 통한 `/deliveries` 이동 경로도 유지했다.
- 현재 경로에 해당하는 메뉴만 선택 상태로 표시되는지 확인했다.
- 장비 검색 결과에서 장비 통합 상세 화면으로 이동하는 흐름을 확인했다.
- 장비 변경 이력의 5단계 대체 계보, 분기, 경로 강조, 확대·축소, 미니맵 및 상세 패널 표시를 확인했다.

## 시각 검수

- 사이드바 너비, 상단 헤더 높이, 콘텐츠 시작 위치가 모든 화면에서 일치한다.
- 페이지 제목, 설명, 카드 제목, 본문, 표 글자의 크기와 굵기가 화면 간 일관되게 적용됐다.
- 카드, 입력창, 버튼, 배지, 표의 테두리·모서리·간격이 공통 디자인 토큰을 따른다.
- 라이트·다크 모드 모두에서 텍스트 대비와 상태 색상 식별성이 유지된다.
- 요소 겹침, 화면 밖 잘림, 비정상적인 가로 스크롤 및 깨진 정렬이 없다.
- 장비 통합 상세는 정보량에 따라 세로 스크롤되는 정상적인 상세 페이지 구조다.
- 한글 깨짐, 한자·일본어 혼입, 이모지 및 맥락 없는 장식 요소가 없다.
- 로그인 사용자명은 `김책임`으로 통일돼 있다.
- `사원`, `대리`, `과장` 및 `기준정보 관리`가 화면에 포함되지 않았다.

## 발견 및 수정 사항

- 기존 화면 흐름에는 납품 일정 페이지가 있었지만 사이드바 직접 진입 메뉴가 누락돼 있어 메뉴를 추가했다.
- 다크 모드 캡처 시 테마 전환 버튼의 설명 툴팁이 남을 수 있어 캡처 전에 포인터를 이동하고 대기하도록 자동화 절차를 보완했다.
- 수정 후 12개 최종 이미지를 원본 해상도로 다시 열어 공통 프레임과 화면별 배치를 재확인했다.

## 제약 및 프로토타입 가정

- 납품 상태는 현재 `예정`, `진행`, `완료`를 프로토타입 표시값으로 사용하며 실제 운영 규칙은 추후 확정한다.
- 화면 데이터는 공개 저장소용 일반화 목업 데이터이며 실제 회사 자료가 아니다.
- 장비 통합 상세는 1440×900 화면 아래로 추가 정보가 이어지는 세로 스크롤 페이지다.
- 본 문서는 3차 개발 후보의 검수 결과이며, `release/prototype-v3` 브랜치는 사용자 화면 승인 후 생성한다.

## 최종 판정

3차 프로토타입의 공통 프레임, 라이트·다크 모드, 납품 일정 접근성, 핵심 화면 이동 및 자동 검증 결과가 릴리즈 후보 기준을 충족한다. 사용자 승인 전까지 `develop/prototype`에서 유지하며, 승인 후 `release/prototype-v3`로 고정한다.
