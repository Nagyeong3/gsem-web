# 변경 신청 및 처리 현황 화면 검수 기록

## 구현 범위

- 변경 신청번호, 품번, 품명, 변경 유형 통합 검색
- 변경 유형, 처리 상태, 신청자 필터
- 신청자·처리자·처리일과 변경 전·후 비교
- 변경 사유, 변경 근거, 처리 과정 조회
- 장비 통합 상세와 대시보드에서 조회 화면으로 이동

## 자동 검사

| 검사 | 결과 |
|---|---|
| TypeScript 타입 검사 | 통과 |
| ESLint | 통과 |
| Vitest | 10개 파일, 22개 테스트 통과 |
| 프로덕션 빌드 | 통과 |
| Playwright 변경 신청 시나리오 | GitHub Actions에서 확인 |

## 프로토타입 가정

- `접수`, `검토 중`, `처리 완료`는 화면 검증용 임시 상태값이다.
- 처리 단계와 상태 전이 규칙은 아직 확정하지 않았다.
- 실제 승인·반려·변경 저장 기능은 제공하지 않는다.
- 변경 근거는 문서 저장 기능이 아니라 조회 화면의 간략한 설명값으로만 표현한다.
- 실제 회사 자료 대신 일반화된 품번, 장비명, 담당자명만 사용한다.
