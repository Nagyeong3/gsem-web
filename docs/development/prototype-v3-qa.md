# 3차 프로토타입 화면 검수 결과

## 검수 대상

- 화면: 장비 변경 이력
- 기준 해상도: 1440×900
- 테마: 라이트 모드, 다크 모드
- 검수 실행: GitHub Actions 품질 검사 21번
- 최종 결과: 통과

## 기능 검수

- 5단계 장비 대체 계보 표시
- 하나의 단종품에서 여러 대체품으로 분기되는 관계 표시
- 하나의 품목에 여러 사업이 적용되는 정보 표시
- 장비명·품번 검색 및 사업·상태 필터 제공
- 확대·축소, 화면 맞춤, 이동, 미니맵 제공
- 선택한 변경 경로 강조 및 우측 상세 로그 연동
- 실제 승인·수정 기능 미제공

## 화면 검수

- 사이드바 176px, 상단 헤더 58px 규격 유지
- 페이지 제목, 설명문, 필터, 그래프, 상세 패널의 시작선 일치
- 5개 단계 제목과 각 열의 장비 노드 정렬 확인
- 모든 노드와 연결선이 캔버스 안에 표시되는지 확인
- 미니맵과 하단 노드가 겹치지 않는지 확인
- 라이트·다크 모드에서 텍스트 및 상태 색상 대비 확인
- 한글 깨짐, 한자·일본어, 금지 직급, 기준정보 관리 메뉴 없음 확인
- 사용자명 `김책임`, 담당자명 `김책임`·`이선임` 확인
- 가로 넘침, 콘솔 오류, 요소 겹침 없음 확인

## 발견 및 수정한 문제

1. 최초 캡처에서 5단계 하단 노드가 미니맵 영역과 시각적으로 겹쳤다.
   - 하단 분기 위치를 재조정하고 미니맵 크기를 축소했다.
2. 최초 라이트 모드 캡처에서 미니맵 노드 대비가 약했다.
   - 노드 초기 크기, 배경색, 선 색상, 마스크 투명도를 명시했다.
3. 초기 화면 캡처 시 미니맵 측정이 완료되기 전에 촬영될 가능성이 있었다.
   - 그래프 렌더링 안정화 시간을 E2E 시나리오에 추가했다.

## 프로토타입 가정

- `사용 중`, `단종`, `대체 예정`은 화면 검증용 상태값이다.
- 변경 사유와 신청·검토·승인·완료 단계는 화면 검증용 가정이다.
- 품번, 사업명, 장비명, 담당자 정보는 일반화한 목업 데이터다.
- 실제 DB 구조와 승인 업무가 확정되면 데이터 모델과 처리 단계를 다시 맞춘다.
