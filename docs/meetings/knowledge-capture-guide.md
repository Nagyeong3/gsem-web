# 지원장비 관리시스템 지식 수집 가이드

> 목적: 이틀 동안 회사에서만 확인할 수 있는 업무 규칙을 최대한 확보한다.

## 회의에서 반드시 확인할 질문

- [ ] 장비 정보 등록부터 납품 완료까지 실제 처리 순서는?
- [ ] 단종 발견부터 대체품 확정까지 실제 처리 순서는?
- [ ] 장비·납품·변경 신청에서 실제 사용하는 상태명은?
- [ ] 동일 장비에 여러 품번이 생기는 경우와 연결 기준은?
- [ ] 사업별로 대체품이 달라질 수 있는가?
- [ ] 대체품 하나가 여러 단종품을 대체할 수 있는가?
- [ ] 네 가지 품목 유형의 공통 항목과 서로 다른 항목은?
- [ ] 납품 일정·수량의 원천과 변경·지연 처리 방식은?
- [ ] 역할별 조회·등록·수정·승인 범위는?
- [ ] 잘못 변경된 정보의 정정 방법과 이력 보존 방식은?

## 시간이 남으면 확인할 질문

- 검색 결과에서 반드시 보여야 하는 열은?
- 가장 자주 쓰는 검색어와 필터는?
- 장비 상세에서 가장 먼저 보는 정보는?
- 대시보드는 개인 업무와 전사 현황 중 무엇이 중심인가?
- 트리에는 어떤 관계를 표시하고 어떤 이력은 로그로 분리하는가?
- 담당자가 동시에 여러 명일 수 있는가?
- 납품 수량 일부만 완료되는 경우는 어떻게 표시하는가?
- 교정과 품보 형태의 표준 코드가 존재하는가?

## 회의 직후 체크

- [ ] 확정·의견·미확정을 구분했는가?
- [ ] 실제 업무와 희망 기능을 구분했는가?
- [ ] 상태명을 현업 표현 그대로 기록했는가?
- [ ] 업무 흐름의 시작자와 완료 조건을 기록했는가?
- [ ] 복수 관계와 예외 사례를 기록했는가?
- [ ] 마스터 파일의 열 이름을 확보했는가?
- [ ] 실제 사내정보를 공개 저장소에 올리지 않았는가?
- [ ] 다음 회의에서 확인할 질문을 남겼는가?
