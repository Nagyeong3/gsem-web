# 지원장비 관리시스템 디자인 기준

## 1. 적용 범위

기준 시안 3장의 공통 구조를 분석해 추가 시안에 적용할 프로토타입 디자인 토큰을 정의한다.

기준 파일의 원본 해상도는 `1672×941`이며, 신규 시안은 요청 규격인 `1440×900`으로 제작한다. 따라서 기존 시안의 시각적 비율을 유지하되 픽셀값은 1440×900 작업영역에 맞춘 공통 토큰으로 통일한다.

| 항목 | 토큰 | 값 |

## 6. 테두리와 그림자

- 카드는 `1px solid #D9E2EC`를 기본으로 한다.
- 일반 카드는 별도 그림자를 사용하지 않는다.
- 모달·드로어처럼 떠 있는 계층에만 `0 8px 28px rgba(10, 31, 68, 0.12)`를 사용한다.
- 선택된 카드나 행은 옅은 파란색 배경과 브랜드색 테두리로 표현한다.
- 과도한 입체감, 글래스 효과, 장식용 그라데이션을 사용하지 않는다.

## 8. 레이아웃 원칙

- 사이드바와 상단 헤더는 모든 화면에서 같은 좌표와 크기를 사용한다.
- 페이지 제목과 설명은 콘텐츠 좌측 시작선에 정렬한다.
- 상단에는 검색·필터, 중앙에는 핵심 업무정보, 우측 또는 하단에는 상세정보를 배치한다.
- 한 화면에 정보가 많으면 탭과 Section을 사용하되, 작은 카드를 지나치게 많이 나누지 않는다.
- 숫자·일정·상태 비교는 표를 우선하고, 관계나 시간 흐름에만 그래프·타임라인을 사용한다.
- 미확정 상태값은 `프로토타입 가정`임을 문서에 기록한다.

## 9. 기준 시안에서 유지할 요소

- 짙은 남색 사이드바와 파란색 선택 메뉴
- 흰색 상단 헤더와 가는 하단 구분선
- 왼쪽 정렬된 페이지 제목과 설명
- 직선적이고 조밀하지만 숨 쉴 공간이 있는 카드·표
- 파랑·초록·주황·빨강으로 제한한 상태 색상
- `김책임` 사용자 표기
- 책임·선임 직급 체계
- 정식 선형 아이콘

## 10. 금지사항

- 기준정보 관리 메뉴
- 이모지와 장식용 특수문자
- 한자·일본어·깨진 한글
- 실제 사내 데이터처럼 보이는 목업
- 과도하게 둥근 카드, 큰 그림자, 글래스모피즘
- 업무 의미가 없는 차트와 장식
- 화면별로 다른 임의의 글꼴·색상·간격
