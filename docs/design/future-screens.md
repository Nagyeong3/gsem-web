# 후속 화면 제안

현재 요구사항만으로 화면을 확정하기 어려운 기능은 우선순위와 선행 확인사항만 기록한다.

| 화면 | 필요한 이유 | 주요 사용자 | 관련 요구사항 | 시안 전 확인사항 | 우선순위 |
|---|---|---|---|---|---|
| 품목 등록·수정 | 지원장비와 기타 품목을 직접 관리하기 위해 필요 | 지원장비 담당자 | 007, 008, 014~019 | 유형별 공통·개별 필드, 필수값, 수정 권한 | 높음 |
| 개인 알림 및 할 일 | 지연·변경·교정 등 확인 업무를 개인화 | 전체 사용자 | 009, 012, 019, 026 | 개인/전사 범위, 알림 조건, 읽음 처리 | 중간 |
| 교정 일정 관리 | 교정 대상과 예정일을 체계적으로 추적 | 지원장비 담당자 | 019 | 기준일, 주기 계산, 만료 기준, 수행 이력 | 중간 |
| 제조사·구매처 관리 | 업체와 담당자 정보를 일관되게 유지 | 담당자, 구매 담당자 | 017, 021, 026 | 개인정보 범위, 업체 중복 기준, 변경 이력 | 중간 |
| 관리자·권한 관리 | 역할별 조회·수정·승인 범위 설정 | 관리자, 승인자 | 전 요구사항 | 실제 역할 체계, 데이터 공개범위, 승인 흐름 | 중간 |
| 문서 및 자료 관리 | 장비 관련 자료를 연결해 조회 | 담당자 | 022~025 | 저장 방식, 기존 시스템 연계, 버전·DRM | 낮음 |
| 리포트 구성 | 납품·장비 현황을 업무자료로 출력 | 담당자, 승인자 | 006, 013 | 공식 양식, 필수 지표, 출력 권한 | 낮음 |
| 엑셀 Import 검증 | 대량 등록·수정 시 오류 방지 | 지원장비 담당자 | 020 | 컬럼 매핑, 중복 기준, 오류 처리·롤백 | 낮음 |

## 제안 순서

1. 품목 등록·수정의 데이터 항목과 권한을 먼저 확인한다.
2. 교정과 개인 알림은 실제 상태·기준일이 정해진 뒤 설계한다.
3. 문서, 리포트, Import는 운영 규칙과 기존 시스템 연계가 확인된 뒤 진행한다.
